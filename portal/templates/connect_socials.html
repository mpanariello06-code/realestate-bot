🔗 Connect Your Socials

To allow the bot to post listings and track engagement, add your API credentials to the .env file and restart the bot. The instructions for each platform are below.

📘 Facebook & Instagram

  1. Go to Facebook Developers and create an app.
  2. Add the Pages API product.
  3. Generate a long-lived Page Access Token.
  4. Copy your Page ID from Page Settings → About.
  5. For Instagram: enable the Instagram Basic Display or Instagram Graph API and copy your Instagram Business Account ID.
  6. Paste the values into .env:
FACEBOOK_PAGE_ACCESS_TOKEN=your_token
FACEBOOK_PAGE_ID=your_page_id
INSTAGRAM_ACCOUNT_ID=your_instagram_account_id

🎵 TikTok

  1. Go to TikTok Developers and create an app.
  2. Enable the Content Posting API.
  3. Obtain an Access Token and your Open ID.
  4. Paste the values into .env:
TIKTOK_ACCESS_TOKEN=your_token
TIKTOK_OPEN_ID=your_open_id

📊 Google Sheets

  1. Go to Google Cloud Console.
  2. Create a project and enable the Google Sheets API and Google Drive API.
  3. Create a Service Account and download the JSON key file.
  4. Rename the key file to google_credentials.json and place it in the project root.
  5. Share your target Google Sheet with the service account email.
  6. Set the spreadsheet name in .env:
GOOGLE_CREDENTIALS_FILE=google_credentials.json
GOOGLE_SPREADSHEET_NAME=RealEstate Bot Leads
💡 Tip: After updating .env, restart the bot with python main.py.
